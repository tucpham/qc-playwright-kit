# QC Playwright Kit

A shared starter kit that lets projects quickly build a **regression test suite** with Playwright, with AI (Playwright MCP) helping to write and maintain the tests.

> **Core principle: AI builds the suite, AI is not the suite.**
> Playwright MCP is only used while creating/fixing tests. What runs regression is reviewed Playwright Test code, committed to the repo, running deterministically in CI, with no AI involved.

## 3-layer architecture

```
┌──────────────────────────────────────────────────────────────┐
│ Layer 3 - AI layer        AGENTS.md, ai/prompts, .claude/     │  plan -> generate -> heal -> review
│                           .mcp.json (Playwright test MCP)     │  (only used while writing/fixing tests)
├──────────────────────────────────────────────────────────────┤
│ Layer 2 - Project adapter project/  specs/  tests/            │  filled in by each project
├──────────────────────────────────────────────────────────────┤
│ Layer 1 - Core kit        kit/  scripts/  eslint, CI          │  owned by QC, shared, do not edit
└──────────────────────────────────────────────────────────────┘
```

| Folder / file | Layer | Owner | Contents |
|---|---|---|---|
| `kit/` | 1 | QC | Standard config, fixtures (role, cleanup, unique data), role-based auth, BasePage, Toast, DataTable, fillForm, tags |
| `scripts/` | 1 | QC | Traceability, stabilize, guard, CSV import, metrics + quality gate |
| `eslint.config.mjs` | 1 | QC | Rules that block hard waits, XPath, tests without assertions, wrong tags... |
| `.github/workflows/`, `ci/` | 1 | QC | CI templates for GitHub Actions / GitLab |
| `project/project.config.ts` | 2 | Project | Environments, roles, how to log in |
| `project/pages/`, `project/api.ts`, `project/fixtures.ts` | 2 | Project | Page Objects, test data create/cleanup client, fixtures |
| `project/app-map.md` | 2 | Project | Map of screens, roles, flows (for humans and AI) |
| `specs/*.md` | 2 | Project QC/BA | Test cases in the standard format, source of truth for expected results |
| `tests/` | 2 | Project | Regression tests (generated by AI, reviewed by humans) |
| `AGENTS.md`, `CLAUDE.md` | 3 | QC | Mandatory rules for every AI agent |
| `ai/prompts/` | 3 | QC | Standard prompts: plan, generate, heal, review, import |
| `.claude/commands/`, `.claude/agents/` | 3 | QC | `/qc-*` commands for Claude Code + Playwright planner/generator/healer agents |
| `demo-app/` | - | - | Demo app for trying out the kit; delete it when applying to a real project |

## Try it in 5 minutes (with the demo app)

```bash
npm install
npx playwright install chromium     # or set BROWSER_CHANNEL=chrome if Chrome is installed
cp .env.example .env
npm test                            # starts the demo app, logs in 2 roles, runs 7 tests + seed
npm run report                      # open the HTML report
npm run verify                      # typecheck + lint + traceability
npm run stabilize -- tests/regression/tasks.spec.ts
npm run metrics -- --gate release
```

## Main commands

| Command | What it does |
|---|---|
| `npm test` / `test:smoke` / `test:regression` / `test:critical` | Run tests by tag |
| `npm run verify` | Typecheck + lint + traceability (run before opening a PR) |
| `npm run stabilize -- <file>` | Run 5 times in a row, no retries. Must be all green before merging |
| `npm run stabilize:changed` | Same as above, only for new/changed test files vs `origin/main` |
| `npm run guard` | Catch changes that weaken tests (removed assertions, changed expected values, added skip/fixme...) |
| `npm run trace:check` | Cross-check specs <-> tests, report coverage |
| `npm run tc:import -- file.csv <slug>` | Convert Excel/CSV test cases to the standard format |
| `npm run metrics -- --gate pr\|nightly\|release` | Compute metrics and check the quality gate |
| `npm run agents:init` | Regenerate the Playwright agents after upgrading Playwright |
